# Privacy Policy

Olauncher does not collect, store, or transmit any personal data. There are no
accounts, no analytics, no advertising, and no tracking of any kind.

## What the app accesses on your device

- **Installed apps** — to list and launch them from the home screen and app drawer.
- **Usage access** *(optional)* — only to show screen time, and only if you enable it.
- **Accessibility service** *(optional)* — only to lock the screen on a double tap,
  and only if you enable it. It reads no screen content and shares nothing.
- **Calendar** *(optional)* — the Calendar and Events widgets read your device
  calendars to display your events. This data stays on the device and is never sent anywhere.
- **A file you choose** *(optional)* — the Obsidian widget reads only the single
  Markdown file you explicitly pick. No other files are accessed.

## Network

The app makes network requests only for the optional **daily wallpaper** feature,
and only while it is enabled: it downloads a wallpaper image and a list of image
URLs. No information about you is included in those requests.
